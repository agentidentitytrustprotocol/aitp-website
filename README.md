# AITP Website

Public-facing documentation website for the **Agent Identity & Trust Protocol (AITP)**.

- **Live site:** [agentidentitytrustprotocol.io](https://agentidentitytrustprotocol.io)
- **Framework:** [Next.js](https://nextjs.org) + [Fumadocs](https://fumadocs.vercel.app)
- **Content:** Synced from 5 source repos via GitHub Actions

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content Sync

Documentation is pulled from the AITP source repos (siblings under `../`) and
converted to MDX with frontmatter injection, code-aware tag escaping, and
internal-link rewriting.

**Manual sync:**

```bash
./scripts/sync-content.sh
```

`scripts/escape-mdx.py` performs the MDX-hostile-character escaping (placeholder
tags like `<identifier>`, numeric comparisons like `<43`, bare `{`/`}`, and
table-cell pipes inside code spans) while leaving fenced/inline code intact.

**Automated sync:** `.github/workflows/sync-docs.yml` runs on source-repo pushes
(via `repository_dispatch`), on a 6-hour schedule, or manually, and opens a PR
with the regenerated `content/`.

## Content Sources

| Section | Route | Source repo | Source dir |
|---------|-------|-------------|------------|
| Documentation | `/docs/*` | `agentidentitytrustprotocol` | `docs/` |
| Specification | `/spec/*` | `agentidentitytrustprotocol` | `rfcs/` |
| Registry | `/registry/*` | `agentidentitytrustprotocol` | `registries/` |
| Implementation | `/implementation/*` | `aitp-rs` | `README.md` + `docs/` |
| SDKs | `/sdks/*` | `aitp-rs` | `docs/sdk-{python,node}.md` |
| Control Plane | `/control-plane/*` | `aitp-control-plane` | `README.md` + `docs/` |
| Playground | `/playground/*` | `aitp-playground` | `README.md` + `docs/` |
| Console | `/console/*` | `aitp-ui-console` | `README.md` + `docs/` (noindex) |

The live Console app links out to `https://console.agentidentitytrustprotocol.io`.

## Project Structure

```
app/                       # Next.js App Router pages
  <section>/               # One route group per content section (8 total)
  community/               # Community page
  e2e-flow/                # Handshake walkthrough
  page.tsx                 # Landing page
components/                # Landing + docs React components
content/                   # MDX content (synced — committed, regenerated by sync)
lib/                       # source.ts (loaders) + nav-links.tsx
scripts/                   # sync-content.sh + escape-mdx.py
.github/workflows/         # ci, deploy, sync-docs
```

## Deployment

Deployed to Vercel as a **public** site at `agentidentitytrustprotocol.io`.
Build command `next build`; set `VERCEL_TOKEN`, `VERCEL_ORG_ID`, and
`VERCEL_PROJECT_ID` as GitHub secrets for `deploy.yml`.
