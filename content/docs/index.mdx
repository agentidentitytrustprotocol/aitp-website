The Agent Identity & Trust Protocol (AITP) lets two autonomous agents in
different organizations establish **mutual, capability-scoped trust** — with no
shared verifier in between. These guides are non-normative companions to the
[specification](/spec); when in doubt, the RFCs are authoritative.

## Start here

- [**Architecture**](/docs/architecture) — the problem AITP solves and how the pieces fit together.
- [**Ecosystem**](/docs/ecosystem) — which AITP repository owns what, and where to go for each task.
- [**Implementer Quickstart**](/docs/implementer-quickstart) — the shortest path to a working peer agent.
- [**Integration Guide**](/docs/integration-guide) — wire AITP into an existing agent or service.
